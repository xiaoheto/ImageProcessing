# 人脸表情识别任务

## 项目描述

本项目旨在使用PyTorch构建一个人脸表情识别模型，能够准确地识别人脸图像中的表情，并进行分类。通过这个项目，学生应学会使用深度学习技术来处理图像数据，理解卷积神经网络（CNN）在人脸表情识别中的应用。

## 任务要求：

- 数据集获取：选择一个适合的人脸表情识别数据集，例如FER2013等，并进行数据预处理。（已上传）
- 模型构建：设计并实现一个基于PyTorch的卷积神经网络模型，用于人脸表情识别任务。(模型自行编写，最终性能以测试精度为准)
- 模型训练：使用数据集对模型进行训练，并调整超参数以获得最佳性能。
- 模型评估：评估训练好的模型在测试集上的准确率表现。
- 结果展示：展示模型在新样本上的表情识别效果，并分析模型的优缺点。新样本需要包含小组同学自行拍摄的表情照片12张，每组表情类别4张，每人提供一组，可自行拍摄。

## 提交要求：
1.包含完整的代码实现，包括数据处理、模型构建、训练和评估等部分。
2.提供项目报告，介绍项目背景、方法、实验结果和分析等内容。（每人一份）
3.提交训练好的模型文件，并展示模型在测试集上的表现结果。（现场检查）
## 评分标准：
- 代码实现的完整性和可读性（30分）：
    - 代码能够完整地实现数据处理、模型构建、训练和评估等必要功能。
    - 代码结构清晰，变量和函数命名规范，易于阅读和理解。
    - 代码注释充分，包括对关键步骤和算法的说明。
- 模型的准确率和性能表现（40分）：
    - 模型在测试集上的准确率不低于70%，并根据精度作为得分标准。
    - 模型在不同表情类别上精确率均匀分布，并没有出现明显的偏差。
    - 模型具有较好的泛化能力，能够处理新样本的表情识别任务。
    - 提示：提高模型准确率的方法：（1）设计更优的模型；（2）使用更多的训练数据。可在给定的数据集上找到更多训练数据，提高精度。
- 项目报告的清晰度和深度分析能力（30分）：
    - 项目报告清晰明了，包含项目背景、方法、实验结果和分析等内容。
    - 报告能够详细描述所选择的数据集、模型架构和训练过程。
    - 报告能够对实验结果进行充分的分析，讨论模型的优缺点，并提出改进方案。
